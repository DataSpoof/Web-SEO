# 工作流路由与交接

## 入口判断

| 当前材料或目标 | 下一技能 | 必须交付的中间结果 |
|---|---|---|
| 只有自然搜索竞品表或 Semrush 原始导出 | `backlink-source-prep` | 源文件登记、合并候选、排除表、优先候选、统计报告 |
| 已有候选域名，要找工具提交和产品收录入口 | `backlink-batch-expansion` | 批量线可执行池、备用池、排除表 |
| 已有媒体或投稿候选，要筛文章机会 | `backlink-quality-expansion` | 质量线免费候选、付费/待确认候选、排除表 |
| 已有两条线路的候选，需要去重或制表 | `backlink-workbook-delivery` | 去重记录、冻结批次、工作簿、质量检查报告 |

## 允许的组合

- 仅补批量线：批量扩量 → 表格交付。
- 仅补质量线：质量扩量 → 表格交付。
- 只整理源表：源表整理后停止，不擅自进入筛选。
- 只重做工作簿：使用现有已筛候选和历史表，不重新研究网站。
- 全流程：源表整理 → 两线并行筛选 → 单点去重和交付。

## 恢复任务

恢复时先读取阶段清单和质量检查报告，确认最后一个已完成阶段。不要因为看到最终文件名就假设中间数据完整，也不要重新分配已冻结批次。

## 数量口径

- 原始行数：源文件中的非空数据行，可包含重复。
- 合并候选数：标准化后的“目标品牌—引荐域名”组合。
- 唯一域名数：跨目标去重后的根域名数量。
- 筛选通过数：进入某条线路候选池的记录。
- 最终行数：工作簿中免费和付费工作表的数据行总和。
- 实际提交数、公开收录数：只能由执行结果证明。

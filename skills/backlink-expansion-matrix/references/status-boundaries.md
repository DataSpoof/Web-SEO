# 状态边界

## 研究和筛选状态

`原始来源 → 已标准化 → 优先候选 → 已找到入口 → 已通过线路筛选 → 已分配批次 → 已导出`

“备用池”和“已排除”是分支状态，不得写成已通过。

## 执行状态

`待提交 → 已提交 → 收到回执 → 已公开 → 公开页已检查`

终止状态可以是：已拒绝、入口失效、强制回链、费用不符、品牌不符、重复收录。

## 证据能证明什么

| 证据 | 最多能证明 |
|---|---|
| Semrush 或竞品外链 | 存在候选来源关系 |
| 搜索结果或公开页面 | 页面当时可见 |
| 提交表单 | 存在可能的提交入口 |
| 工作簿中的候选行 | 已整理为待执行候选 |
| 提交回执 | 已完成一次提交动作 |
| 公开详情页 | 页面已公开 |
| 页面复查和链接检查 | 当时仍公开且链接状态已检查 |

不能用较低阶段的证据替代较高阶段结论。

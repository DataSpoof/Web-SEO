## 编辑原则

最小成品约定还包括：图文风格尽量贴近已有品牌资料；正文图片之外默认单独交一张封面，不顶替正文首图；内容独立有用、链接真实相关，不批量写低价值挂链稿。用户指定多锚多链接按原要求保留并核对，不按数量一刀切，也不承诺零误判。稿件语言须符合写前从首页推送/Trending/Popular/Featured 等实际文章核定的主流语言；界面语言或可编辑语言不算受众证据。沿用现有一轮核验，细则见[编辑标准](references/editorial-standard.md)及平台匹配技能。

- 在冻结选题内讲清“什么读者，在什么情况下，要解决什么问题，读完能做什么”，不能只用“信息型文章”或“初学者”代替具体任务。正文应提供能照做的步骤、有依据的选择或清楚的理解，按题材取所需内容，不强制全部项目。即使暂不考虑推荐，正文仍应独立有用；实际交付必须保留用户确认的次要、透明 CTA。
- 重要事实须有与具体表述相符的来源。证据只支持部分场景时，收窄范围并说明限制；没有依据时，删除该事实或明确尚未验证，不能只加“可能”“通常”就保留。分析和建议要说明推理依据；虚构示例须明确为假设，不能冒充实测或真实案例。
- 默认让 W 用一个 `research/evidence-pack.json` 连续承载本篇关键词、本地化、来源、事实边界和图片计划；可生成查阅视图，不双写研究文档。项目内稳定证据只在精确匹配时引用并记录本篇差异，无命中不造空缓存。WQ 由同一 W 锁定候选、反方自查、定向修复并绑定最终哈希为 `AUTHOR_QA_READY`；只有用户明确选择的 WR 才由独立 R 完整审查引用记录和成稿。WQ 的重大风险应记录为 `OWNER_DECISION_REQUIRED`，不自动创建独立审稿。可选成文前研究挑战也只存在于用户明确选择的 WR。
- G 冻结的 `topic_slot` 约束读者任务、核心意图、市场、差异化角度和禁止偏离项；通常不冻结最终标题。用户必保留主词另由共享 `keyword_requirements` 保护并逐篇继承，不能降格为研究种子或被延伸角度替代。W 只可调整未锁定候选词、符合约定的本地化及标题附加措辞；若须改用户要求或换读者问题、市场、承诺，交回原 G。见[关键词要求](../../docs/keyword-requirements.md)。
- 先按品牌网站、地区搜索结果、翻译兜底选定自然表达。默认标题与预期 H1 保留用户关键词的全部核心含义，用不同句式突出各篇读者问题，避免同一长前缀加不同后缀；只有明确锁定原文或未变更的旧契约才要求完整短语。共同主词记录不得被角度词替换，跨语言不硬贴英文。正文兑现承诺，不借变化制造新收益；平台标题默认等于基准稿标题。细则见[编辑标准](references/editorial-standard.md)。
- 搜索结果按需用于判断内容类型、形式和答案缺口，不合并竞品大纲、不把平台热度当成搜索需求。优先复用范围与时效适用的已有证据，不规定样本数量或新增研究报告；跨语言仍遵守下述选词顺序。
- 结构由问题和信息决定，不固定关键词次数、章节数量、清单长度或段落四步式。按需补充已有答案中笼统的步骤、适用条件、常见错误、选择取舍或解释难点的示例；这些是思考方向，不是必填清单。删去重复定义、空泛好处与重复小结，普通稿不要求原创实验或新增数据。
- 风格以用户提供的品牌说明为首要依据，再参考已核验的目标页面；语气、专业程度、称谓、产品术语和适用配图应与品牌相呼应，同时适应目标语言与平台。正文保持独立价值，不照搬广告、不冒充官方、不虚构使用体验；品牌风格不能支持无依据的事实。复用已有资料，无资料时用清晰克制的文风，不声称已匹配品牌。不另扫全站、生成风格报告或增加审批；在现有自查中判断点击前后的语气、受众、用途和收益预期是否明显脱节，修正文案但不擅改冻结 CTA、链接或定位。
- 多语言表达先采用同语言、同地区、同意图的现有品牌站用语，再查地区 SERP 自然变体，最后才可在两次无共识检索后使用有记录的 `MODEL_TRANSLATION_FALLBACK`。Google Trends 如可用，只比较英文概念和英文长尾候选，且仅作全球相对关注度背景；不能证明本地用语、搜索量、低基数/高势头、本地需求、商业意图或模型能力。数据不足、无 `Breakout` 或无清晰趋势时，不得强求趋势证据；长尾读者问题仍由品牌站与地区 SERP 的有边界证据决定。平台资料仅可影响技术深度、示例形式、语气与交付风险，不能证明关键词、自然变体、搜索意图、当地需求或热门度。
- 配图必须准确解释相邻方法，同一示例的识别重点保持连贯；不能靠“仅示意”图注掩盖错误操作或术语。适用指南、教程、对比、评测和长解释文时，以 `LEAD`、`MIDDLE`、`CLOSING` 覆盖组织图片；每张图有独立读者作用、Alt、图注、位置和视觉审查，不能用首图或尺寸凑数。
- 示例性质集中说明，局部只保留影响选择或操作的限制，不逐段重复免责；必要事实边界和用户要求的披露不能删。推荐须说明产品在本篇任务中的具体作用，保留必需 CTA，不用批量通用尾段替代任务衔接。与图文准确性一起并入原有一轮核验，只修受影响部分；细则见[编辑标准](references/editorial-standard.md)。
- 当前 `article-package.json@1.5` 固定 `canonical/article.html`、metadata、evidence pack 与 visual manifest 为唯一上游来源；同一编译器从这些声明来源生成 HTML 主交付页和 Markdown 备用投影。适用 WQ/WR 质量角色语义审 HTML 与源数据；Markdown 仅 `COMPANION_DUAL_READ_REQUIRED` 时语义双读。WQ 任何绑定后可见改动须重新作者自查，不能使用独立 R 的 Delta 名义。
- 唯一基准稿的标题层级是写作意图与本地结构审稿对象；平台读者页的最终层级只能由 `HUMAN_ACCEPTED` 后的公开渲染视觉裁定。

具体执行由 `blog-writer`、`blog-review` 和其引用的[编辑标准](references/editorial-standard.md)、[跨语言 SEO 说明](references/cross-language-seo.md)承担。机器字段、状态码、文件路径与 Skill ID 保持不变。

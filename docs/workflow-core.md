# 博客短流程

压缩、恢复或交接后完整重读本页，再读用户确认的任务、当前稿和开放问题。其他资料按需读取。

## 角色与顺序

G（主控）确认需求并验收，W（作者）制作成品，R（独立审稿）检查质量。质量与效率同等重要。

最终交付是带公开图片 URL 的完整 HTML 和 Markdown 全文，正文原位显示或引用图片，只包含读者内容与图注。封面、SEO 信息、摘要及图片资料在正文之外，草稿预览保存在独立的 `preview/` 目录。

1. **调研与方案。** G 收集要求，汇总逐篇读者问题、产品事实、关键词/本地化、平台匹配、品牌风格、CTA（行动引导链接）、图片与交付安排。每次新任务给一份必要人工准备清单。一般营销限制作为风险提示，结合具体稿件与用户实际发布经验判断；保留候选和已确认的本地任务，平台取舍由用户决定，详见[平台匹配](../skills/blog-gate/references/platform-matching.md)。
2. **用户确认。** 写前交出有依据、能开写的建议：推荐选题、目标读者与问题、正文安排、产品承担的步骤及必要未知。平台内容帮助判断读者与深度，模型设计各篇问题与主要帮助；独立选题不只换标题或例子，同题本地化按用户要求。事实须核实，来源应影响方案；只补会改变建议的缺口，不要求已有同题热门稿。用户确认后安排作者、写正式稿和生图。一份 `task-plan.json` 保存共享要求与逐篇差异，附原确认来源；要求内的角度、标题、结构和例子由 W 自主优化，明确锁定项除外。
3. **连续成稿。** 复用少量可见 W，可安全并行；各写 `articles/<ID>/`。复用有效共享资料，连续完成研究、Markdown、SEO 信息、正文图和封面；由 W [选择图床](../skills/blog-writer/references/image-hosting.md)、上传本篇可公开图片并核验直链，生成完整 HTML/Markdown 图文页。
4. **独立审核。** W 备齐并机械检查最终 HTML/Markdown 和素材后交 R。R 实际看渲染页、全部图片和重要来源，完整审核一次，同时沿用写前依据判断正文是否帮助目标读者；新角度和模板偏好不单独构成问题。真实问题由原 W 修复、原 R 复核改动与直接影响。结论简短，绑定当前成品。缺审核结果或重大问题无法解决时报告 G/用户。
5. **验收交付。** R 通过当前版本后，G 对照原确认验收数量、映射、语言、关键词含义、CTA/披露、链接、图片及双载荷入口，交用户发布。
6. **人工发布。** 人工登录、粘贴图文、预览、发布和修复，必要时补插平台未保留的图片。等待时保存进度并结束执行。账号注册/登录与最低设置按专项授权执行；机器不得写入稿件编辑器、向博客平台上传图片、保存草稿、发布、删除或改指纹浏览器客户端。
7. **公开页检查。** 用户回传 URL 和接受/需修复结论后，同一 G 只读核对传递。标题层级看公开页渲染视觉；默认检查桌面公开页，用户提出需要时再检查手机端。图片显示大小依据本次实际渲染检查溢出、异常裁切及可读性，不按原图像素机械判定。平台侧问题给人工合并修复提示，G 只复核相关项，不重开写作审稿；本次检查范围内缺少实际显示证据记未核验。用户要求改稿或素材时回原 W/R。人工接受且公开检查通过计完成。

## 交付要求

- 平台来自用户给定且确认范围，一文一平台；语言依据实际首页、热门或精选文章。平台、语言、读者任务等范围冲突交用户决定。
- 每篇文章标题/预期 H1 自然表达主关键词全部保护含义并突出本篇问题；逐字锁定按原文。页面 `seo_title` 单独精简，与 H1 同主题、同承诺，按语言及显示宽度判断长度；平台支持独立字段时分别填入，否则说明联动限制。H2/H3 写清对象与子问题。跨语言表达优先适用品牌用语，再查地区变体，两次核验仍无共识时记录模型翻译。Trends 可选，仅作英文全球相对关注度背景。
- 正文独立有用，事实有依据，示例与实测区分。目标产品文字外链的可见锚文本须含对应的已确认品牌名，表达自然，不强塞关键词；指定 CTA、链接次数和披露保留，锁定文案冲突交用户决定。推荐次要、贴题，默认关系为 founder（创始人）；多锚、多链接仍须相关且符合适用政策。避免低价值挂链；排名、收录和平台保留由外部系统决定。
- 图片应帮助读者理解正文，内容丰富、呼应品牌，所示操作、比较和对应关系准确；构图、表现形式、工具和制作顺序按需自主选择。按确认数量、比例与首中尾要求制作，正文图外默认另备封面。编号 PNG/JPG/JPEG，实际查看每张图，准确填写 Alt（图片替代文本）、图注和文内图位。
- 维护一份 Markdown 和图片，图床公开地址写入各图记录，程序生成完整 HTML/Markdown 图文页并处理计数、一致性。页面顺序：标题、含真实图片和读者图注的完整正文、SEO title/tags/description、独立 excerpt（摘要），之后单列封面及图片资料。正文不含中文操作卡；公开 URL 默认必需，漏填配置也不会关闭。

## 工作与恢复

G 维护共享要求及进度，W 写本篇。角色持续复用，工作树按真实写入冲突、风险隔离或用户要求建立，保留现有模型配置。正常只读原要求、最新产物和真实问题。

旧 `campaign.json`、文章包和审稿索引项目按原确认与接口恢复，保留历史。程序结果证明机械一致性；独立审稿、用户接受和公开检查分别记录。
